# Crash Local: Jungle & Supra Drift

Crash Bandicoot-inspireret 2D-platformspil & Toyota Supra MK4 multiplayer drift-spil udviklet i **Godot 4.7 (GDScript)** til Android (2–4 spillere over lokalt Wi-Fi/Hotspot på OnePlus 12R / ARM64).

## Spiltilstande
- **Race Mode (Jungle Sprint):** 6400 px lang junglebane i 4 zoner med kløfter, bevægelige tempelplatforme, junglefjender, pigfælder og 5 kassetyper.
- **Arena Mode (3 Liv Kamp):** Flerlags kamparena med 3 liv pr. spiller, spin-knockback, TNT, hoppe-kasser og 90s kamptimer.
- **Supra Drift Mode (Toyota Supra MK4):** Top-down drift-racerbane (3 omgange) for 2–4 spillere eller solo mod AI-Bot med dækrøg, dækspor på asfalten, drift-point, turbo-opladning og udstødningsflammer.

## Styring & Lokal Multiplayer
- **Venstre side:** Analog virtuel controller-thumbstick til trinløs styring i alle modes.
- **Højre side:** `JUMP` & `SPIN` (Race/Arena) eller `DRIFT` & `TURBO` (Supra Drift).
- **Multiplayer:** Alle telefoner på samme Wi-Fi/hotspot -> Vært trykker **OPRET RUM** -> Gæster indtaster værtens IP og trykker **TILSLUT** -> Vært trykker **START**.
